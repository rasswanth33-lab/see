## 15. Responsive Design

The desktop reference is the source of truth.

Support:
- Desktop
- Laptop
- Tablet
- Mobile

On mobile:
- Header becomes a hamburger menu
- Cards stack vertically
- Hero visual moves below text
- Typography scales appropriately
- Buttons remain easy to tap
- No horizontal scrolling
- Images retain correct proportions

Do not redesign the mobile version into a different visual identity.

---

## 16. Animation

Use only subtle animation:
- Fade-in
- Slight slide-up
- Card hover
- Button hover
- Image hover
- Smooth scrolling
- Small pixel movement

Avoid excessive motion, flashy effects, or heavy 3D animations.

---

## 17. Performance

- Optimize images
- Use lazy loading
- Use responsive images
- Keep JavaScript efficient
- Avoid unnecessary dependencies
- Optimize Core Web Vitals
- Ensure fast mobile loading

---

## 18. SEO

## 19. Accessibility

Provide:
- Keyboard navigation
- Good color contrast
- Accessible forms
- Image alt text

- Mobile-friendly controls

## 20. Content Principle

Keep everything **simple and clear**.

Do not use large blocks of text or unnecessary sections.

The visitor should quickly understand:
1. What Seeable Hub does
2. What services it provides
3. What projects it has built
4. What the NFC product does
5. How to contact the company
